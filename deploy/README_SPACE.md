# DayZero

A climate stress-testing engine. Pick any point on Earth; DayZero pulls the
real building footprints and 34 years of real climate history for that spot,
simulates the water balance forward month by month, finds when the system
fails, and searches for the cheapest set of interventions that survives it.

**Source and full documentation:** https://github.com/ItzAditya43/DayZero
**Primary deployment:** https://dayzero-cuy1.onrender.com
